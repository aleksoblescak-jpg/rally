To notice slower typing, Rally needs Accessibility access: System Settings → Privacy & Security → Accessibility → turn on Rally. Pauses are detected without it. Rally only counts key presses, never which keys.

Rally notices when your workday starts, then watches the last hour. Pauses of 3–20 minutes count; a single long break like lunch is ignored. With 3 or more pauses, or slower typing in the afternoon slump, you get one quote that day: weekdays only, never before 9 am, and only once you're back at the keyboard.
